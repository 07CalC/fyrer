<div className="mx-auto max-w-6xl px-6 py-12">
  <h2 className="text-lg font-bold tracking-tight">How it works</h2>
  <Steps>
    <Step title="Describe the graph">
      Put `fyrer.yml` at the repo root. `depends_on: [ui:build]` or bare `build` for same package.

      ```bash
      fyrer list          # every package:task
      fyrer plan build    # preview levels (for reading, not scheduling)
      ```
    </Step>
    <Step title="Run it">
      ```bash
      fyrer run build -n   # CI: plain logs, exit code signals pass/fail
      fyrer run dev        # TUI: all dev servers, streaming logs
      ```

      `api:build` + `ui:build` start together. `web:build` starts the instant `ui:build` succeeds.
    </Step>
    <Step title="Iterate">
      Save a file → `watch: true` restarts. Unchanged `build` tasks hit `⚡ Cached`.

      ```bash
      fyrer run build   # only what changed actually runs
      ```
    </Step>
  </Steps>
</div>

<Columns cols={2}>
  <div>
    ### Built for watching a monorepo run

    | Key | Action |
    | --- | --- |
    | `q` / `Ctrl+C` | Quit, killing every process group |
    | `j`/`k` `↑`/`↓` | Select task |
    | `u`/`d` `PgUp`/`PgDn` | Scroll log |
    | `g`/`G` | Top / tail |
    | `r` | Restart selected task |
    | `K` | Kill selected task |

    <Tip>
      In CI: `fyrer run build -n` — every line is `[package:task]` colorized, no TUI.
    </Tip>
  </div>
  <div>
    ### Every option a task can take

    ```yaml
    tasks:
      build:
        cmd: bun build src --outdir dist
        inputs: [src/**, package.json]
        outputs: [dist/**]
        ignore: [node_modules/**]
        cache: true
        timeout: 5m
        cwd: subdir
        env: { NODE_ENV: production }
        env_file: .env.production
    ```

    Validated at startup: unique names, relative `root`/`cwd`/`env_file`, valid globs, `cache` ≠ `persistent`/`watch`.
  </div>
